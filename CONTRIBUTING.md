# 🤝 Guía de Contribución - SOC L1 Lab

¡Gracias por tu interés en contribuir al proyecto SOC L1 Lab!

## 🎯 ¿Cómo Contribuir?

### 1. Reportar Problemas
- Usa la sección de **Issues** de GitHub
- Incluye: descripción, pasos para reproducir, comportamiento esperado vs actual
- Etiqueta apropiadamente (bug, enhancement, documentation)

### 2. Sugerir Mejoras
- Crea un **Issue** con la etiqueta `enhancement`
- Describe claramente la mejora propuesta
- Explica el beneficio para el proyecto

### 3. Contribuir con Código
1. **Fork** el repositorio
2. **Crea una rama** (`git checkout -b feature/amazing-feature`)
3. **Realiza tus cambios** siguiendo los estándares
4. **Haz commit** (`git commit -m 'Add amazing feature'`)
5. **Push a la rama** (`git push origin feature/amazing-feature`)
6. **Abre un Pull Request**

## 📋 Estándares de Código

### Estructura
- Mantén la estructura de directorios existente
- Usa nombres descriptivos para archivos y funciones
- Documenta funciones complejas

### Documentación
- Actualiza `README.md` si es necesario
- Documenta nuevas características
- Mantén la guía de ética actualizada

### Pruebas
- Asegúrate que los cambios no rompan funcionalidad existente
- Ejecuta las pruebas antes de hacer commit
- Agrega pruebas para nuevas características

## 🚀 Tipos de Contribuciones Buscadas

### 1. Nuevos Escenarios
- Simulaciones de ataques adicionales
- Configuraciones de SIEM avanzadas
- Integraciones con nuevas herramientas

### 2. Mejoras de Documentación
- Traducciones a otros idiomas
- Tutoriales paso a paso
- Mejoras en guías existentes

### 3. Correcciones de Bugs
- Errores en scripts
- Problemas de configuración
- Issues de compatibilidad

### 4. Optimizaciones
- Mejoras de rendimiento
- Reducción de recursos
- Automatizaciones
